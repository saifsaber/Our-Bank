# دليل تشغيل الـ Dry-Run (تداول ورقي) على أسعار Bybit الحقيقية

الهدف: نشغّل 3 بوتات **بفلوس وهمية** على أسعار Bybit الحقيقية لمدة **4 لـ 8 أسابيع**، عشان نشوف أداء الاستراتيجيات على بيانات جديدة خالص محدش شافها قبل كده. ده الاختبار الحقيقي الوحيد اللي فاضل بعد الباك تست (شوف [`reports/SUMMARY.md`](../reports/SUMMARY.md)).

| البوت | الاستراتيجية | صفحة المتابعة (FreqUI) |
|---|---|---|
| `rsi` | RsiMeanReversionBaseline | http://127.0.0.1:8081 |
| `ema` | EmaCrossBaseline | http://127.0.0.1:8082 |
| `freqai` | FreqAIStrategy (LightGBM) | http://127.0.0.1:8083 |

كل بوت معاه **100 USDT وهمي**، وله قاعدة بيانات لوحده (`user_data/dryrun-rsi.sqlite` و `dryrun-ema.sqlite` و `dryrun-freqai.sqlite`).

> **مهم:** الـ dry-run **مش محتاج API key خالص** ومفيش أي فلوس حقيقية بتتحرك. لو حد طلب منك API key عشان "التجربة"، ماتديهوش.

## قبل ما تبدأ: غيّر الباسوردات (مرة واحدة)

في فولدر `config` فيه 3 ملفات: `config.dryrun.rsi.json` و `config.dryrun.ema.json` و `config.dryrun.freqai.json`.
افتح كل واحد بـ Notepad (كليك يمين ← Open with ← Notepad)، وهتلاقي جزء زي ده:

```json
"password": "CHANGE-ME-vEflFXHuwZbrQnKY",
"jwt_secret_key": "CHANGE-ME-kJAXIECnIBPwmlQZ-GcbBMyieAhfAPgCe",
"ws_token": "CHANGE-ME-vrgrN5CO6XivjZhk"
```

- غيّر الـ 3 قيم لكلام عشوائي طويل من عندك (حروف وأرقام بس، من غير مسافات أو علامات `"`).
- **الـ password** هو اللي هتدخل بيه على صفحة البوت، فاكتبه في مكان آمن. الاتنين التانيين محدش بيحتاج يفتكرهم.
- خلي كل بوت بباسورد مختلف. اسم المستخدم في التلاتة `ourbank`.
- احفظ الملف (Ctrl+S) وخلي بالك ماتمسحش أي فاصلة `,` أو علامة تنصيص.

## الاختيار (أ): على جهازك الويندوز بـ Docker Desktop

ده أسهل اختيار. العيب الوحيد إن الجهاز لازم يفضل شغال ومتوصل بالنت طول مدة التجربة (لو قفلته، البوت بيقف ويكمل لما تفتحه تاني، بس هيفوّت الصفقات اللي كانت في الوقت ده).

### 1. تسطيب Docker Desktop

1. نزّل Docker Desktop من الموقع الرسمي: https://www.docker.com/products/docker-desktop/ (اختار Windows).
2. سطّبه بالإعدادات الافتراضية. لو سألك عن **WSL 2** وافق. ممكن يطلب إعادة تشغيل الجهاز.
3. افتح Docker Desktop واستنى لحد ما يكتب إنه شغال (Engine running). مش محتاج تعمل حساب.
4. من الإعدادات (Settings ← General) فعّل **Start Docker Desktop when you sign in** عشان يشتغل لوحده مع الجهاز.

### 2. تنزيل المشروع

- من صفحة المشروع على GitHub: زرار **Code** ← **Download ZIP**، وفك الضغط مثلاً في `C:\Our-Bank`.
- (أو لو عندك git: `git clone <رابط الريبو> C:\Our-Bank`.)

### 3. التشغيل

1. افتح فولدر `C:\Our-Bank` في File Explorer، واكتب في شريط العنوان `powershell` واضغط Enter. هيفتح لك شاشة سودا/زرقا في الفولدر ده.
2. اكتب:

```powershell
docker compose up -d
```

أول مرة هياخد وقت عشان ينزّل البرامج (بتاخد حوالي 4 جيجا على الهارد، فخلي عندك مساحة فاضية 10 جيجا على الأقل). بعد كده هيكتب إن الـ 3 بوتات `Started`.

3. اتأكد إنهم شغالين:

```powershell
docker compose ps
```

لازم تلاقي `ourbank-rsi` و `ourbank-ema` و `ourbank-freqai` وجنب كل واحد `Up`.

> بوت الـ FreqAI أول ما يقوم بينزّل بيانات حوالي 7 شهور ويدرّب الموديل، فبياخد كام دقيقة قبل ما يبدأ يدي إشارات. ده طبيعي. وبيعيد التدريب لوحده كل 24 ساعة.

### 4. فتح لوحة المتابعة (FreqUI)

افتح المتصفح على http://127.0.0.1:8081 (أو 8082 أو 8083)، واضغط Login:
- **API Url:** `http://127.0.0.1:8081` (نفس رقم البورت)
- **Username:** `ourbank`
- **Password:** الباسورد اللي حطيته للبوت ده

من اللوحة تقدر تشوف الصفقات المفتوحة والمقفولة والربح. **ماتدوسش Force entry / Force exit**، عشان ده بيبوّظ التجربة.

الصفحات دي مفتوحة من جهازك بس (127.0.0.1)، محدش على النت يقدر يوصلها.

### 5. الإيقاف والتشغيل

```powershell
docker compose down      # يوقف التلاتة (السجل محفوظ في user_data)
docker compose up -d     # يشغلهم تاني ويكملوا من مكان ما وقفوا
docker compose logs -f rsi   # تشوف اللوج بتاع بوت (Ctrl+C يخرجك من العرض بس، البوت يفضل شغال)
```

**ماتمسحش فولدر `user_data`**، فيه كل سجل الصفقات.

## الاختيار (ب): سيرفر Linux في أوروبا (Hetzner)

أحسن لو عايز البوت شغال 24 ساعة من غير ما تسيب جهازك مفتوح. التكلفة حوالي 4–6 يورو في الشهر.

### 1. عمل السيرفر

1. اعمل حساب على https://www.hetzner.com/cloud (ممكن يطلبوا تأكيد هوية).
2. **Create Server**:
   - **Location:** ألمانيا (Falkenstein أو Nuremberg) أو فنلندا (Helsinki). **مش** أمريكا ولا سنغافورة (Bybit حاجبهم).
   - **Image:** Ubuntu 24.04.
   - **Type:** أي سيرفر فيه **4 جيجا رام** على الأقل (زي CX22 / CPX21 أو اللي بيقابلهم). الـ FreqAI محتاج رام.
   - **SSH key:** الأفضل تضيف مفتاح SSH. على ويندوز افتح PowerShell واكتب `ssh-keygen` واضغط Enter على كل الأسئلة، وبعدين `type $env:USERPROFILE\.ssh\id_ed25519.pub` وانسخ الناتج في خانة SSH key.
3. بعد ما يتعمل هتاخد **IP** للسيرفر (مثلاً `203.0.113.10`).

### 2. الدخول وتسطيب Docker

من PowerShell على جهازك:

```powershell
ssh root@203.0.113.10
```

وبعدين على السيرفر (انسخ السطور دي زي ما هي):

```bash
apt update && apt -y upgrade
curl -fsSL https://get.docker.com | sh
apt -y install git ufw
ufw allow OpenSSH && ufw --force enable     # يقفل كل البورتات ما عدا SSH
git clone <رابط الريبو> /opt/Our-Bank     # أو ارفع الفولدر بـ scp
cd /opt/Our-Bank
```

### 3. غيّر الباسوردات

```bash
nano config/config.dryrun.rsi.json      # عدّل الـ 3 قيم CHANGE-ME، وبعدين Ctrl+O ثم Enter للحفظ، و Ctrl+X للخروج
nano config/config.dryrun.ema.json
nano config/config.dryrun.freqai.json
```

### 4. التشغيل

```bash
docker compose up -d
docker compose ps
```

البوتات عليها `restart: unless-stopped`، يعني لو السيرفر عمل restart هيقوموا لوحدهم.

### 5. فتح FreqUI من جهازك (نفق SSH)

صفحات البوت مش مفتوحة على النت خالص (أمان). عشان تفتحها، من PowerShell على جهازك:

```powershell
ssh -N -L 8081:127.0.0.1:8081 -L 8082:127.0.0.1:8082 -L 8083:127.0.0.1:8083 root@203.0.113.10
```

سيب الشاشة دي مفتوحة (مش هيظهر فيها حاجة)، وافتح المتصفح على http://127.0.0.1:8081 زي الاختيار (أ). لما تخلص اقفل الشاشة.

> **ماتفتحش** البورتات 8081–8083 في الـ firewall ولا تغيّر `127.0.0.1` في `docker-compose.yml`. النفق أأمن بكتير.

## المتابعة الأسبوعية: تقرير المقارنة

مرة في الأسبوع (مثلاً كل جمعة)، من نفس الفولدر:

```bash
docker compose run --rm report
```

هيطبع جدول، ويحفظه كمان في `user_data/dryrun_report.md`. فيه لكل بوت:

- **Closed trades:** عدد الصفقات اللي اتقفلت.
- **Win rate:** نسبة الصفقات الكسبانة.
- **Fees paid:** الرسوم اللي اتدفعت (وهمياً).
- **Realised net:** صافي ربح/خسارة الصفقات المقفولة **بعد الرسوم** (بالدولار وبالنسبة من الـ 100).
- **Open positions / Unrealised:** الصفقات المفتوحة ومكسبها/خسارتها بسعر دلوقتي.
- **Max DD:** أكبر هبوط في الرصيد من أعلى نقطة وصلها.

وتحتها المقارنة مع، **على نفس الفترة بالظبط**:

- **BTC buy-and-hold:** لو كنت اشتريت بيتكوين يوم ما البوتات بدأت وسبته.
- **Equal-weight BTC/ETH/SOL:** لو قسمت الفلوس بالتساوي على التلاتة وسبتهم.
- **USDT savings:** لو سبت الـ USDT في ادخار بعائد 3.2% سنوي (غيّره لو العائد عندك مختلف: `docker compose run --rm report --savings-apy 4`).
- **Cash:** ما عملتش حاجة (0%).

انسخ التقرير كل أسبوع في ملف أو ابعته، عشان نشوف التطور.

(لو شغال من غير Docker بالـ venv: `.venv/bin/python scripts/dryrun_report.py`.)

## يعني إيه "نجحت"؟

البوت يعتبر ناجح **بس لو** بعد 4–8 أسابيع:

1. **صافي النتيجة بعد الرسوم أعلى من ادخار الـ USDT** في نفس المدة. (موجب لوحده مش كفاية: لو البوت كسب 0.2% والادخار 0.5%، يبقى البوت خسران.)
2. **وأعلى من الشراء والاحتفاظ** (BTC والمحفظة المتساوية) في نفس المدة، **أو** قريب منه بهبوط (Max DD) أقل بكتير.
3. **عدد صفقات معقول.** أقل من 30 صفقة مقفولة = النتيجة غالباً حظ، مش ميزة. RSI و FreqAI بيدخلوا صفقات قليلة، فممكن 8 أسابيع ماتكفيش للحكم عليهم، وده في حد ذاته معلومة.

وخد في بالك:

- **الـ dry-run متفائل:** الأوردر الوهمي بيتنفذ بسعر مثالي. في الحقيقي فيه انزلاق (slippage) وأوردرات ماتتنفذش، فالنتيجة الحقيقية غالباً أسوأ شوية.
- **4–8 أسابيع فترة قصيرة.** سوق طالع أو نازل في الفترة دي ممكن يخلي أي استراتيجية شكلها حلو أو وحش. عشان كده المقارنة مع الشراء والاحتفاظ في **نفس الأسابيع** هي المهمة، مش الرقم لوحده.
- **ماتعدّلش الاستراتيجيات أو الإعدادات في النص.** أي تعديل = التجربة تبدأ من الأول (امسح ملف الـ sqlite بتاع البوت ده).
- مفيش حاجة هنا وعد بربح. نتيجة الباك تست لحد دلوقتي: ولا استراتيجية غلبت الادخار بعد التكاليف.

## قواعد الأمان

**في الـ dry-run:**
- مفيش API key، مفيش فلوس. خانات `key` و `secret` في الإعدادات لازم تفضل فاضية.
- صفحات FreqUI على `127.0.0.1` بس. ماتشاركش الباسوردات.

**لو في يوم قررت تتداول بفلوس حقيقية** (ده مش جزء من الخطة دي، ومحتاج موافقة صريحة بعد نتايج dry-run كويسة):
- اعمل **حساب فرعي (sub-account)** على Bybit فيه المبلغ اللي مستعد تخسره بس.
- مفتاح API **من غير صلاحية سحب (Withdraw)**، صلاحية Spot trade بس.
- اربط المفتاح بـ **IP السيرفر بس (IP whitelist)**.
- المفتاح يتحط في ملف على الجهاز اللي شغال عليه البوت بس (مثلاً `config/config.private.json`، واسمه متجاهَل في git)، **مش** في الريبو ولا في أي شات.
- أقل أوردر Spot على Bybit 5 USDT.

**ملاحظة قانونية:** قانون البنك المركزي والجهاز المصرفي رقم 194 لسنة 2020 (**مادة 206**) بيمنع إصدار أو تداول أو الترويج للعملات المشفرة من غير ترخيص من البنك المركزي المصري، والعقوبات فيها حبس و/أو غرامة من 1 لـ 10 مليون جنيه، والبنك المركزي نشر تحذيرات رسمية (شوف [`docs/research-implementation.md`](research-implementation.md)). الـ dry-run نفسه مفيهوش تداول فعلي، بس أي تداول حقيقي بعد كده خطر قانوني عليك انت شخصياً. اسأل محامي قبل أي خطوة بفلوس حقيقية.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| `docker: command not found` أو `cannot connect to the Docker daemon` | Docker Desktop مش شغال. افتحه واستنى لحد Engine running. |
| بوت حالته `Restarting` | `docker compose logs --tail 50 rsi` وشوف آخر سطر فيه `ERROR`. غالباً غلطة في ملف config بعد تعديل الباسورد (فاصلة أو علامة تنصيص اتمسحت). |
| الصفحة مش بتفتح | اتأكد إن البوت `Up`، وإنك بتفتح `127.0.0.1` مش `localhost` لو في مشكلة. على السيرفر اتأكد إن نفق SSH مفتوح. |
| `Unauthorized` في FreqUI | الباسورد غلط، أو الـ API Url مش نفس البورت بتاع البوت. |
| رسالة إن Bybit مش متاح / 403 | الجهاز أو السيرفر في دولة Bybit حاجباها (أمريكا مثلاً). استخدم سيرفر في ألمانيا/فنلندا. |
| الـ FreqAI مابيدخلش صفقات | طبيعي في أول ساعات (بيدرّب)، وطبيعي كمان إنه يقعد أيام من غير صفقة: عتبة الدخول عالية (توقّع +2% في 12 ساعة). |

## التشغيل من غير Docker (للي بيعرف)

```bash
scripts/setup.sh                 # مرة واحدة: venv + Freqtrade 2026.8
.venv/bin/freqtrade install-ui   # مرة واحدة: صفحة FreqUI
.venv/bin/freqtrade trade -c config/config.dryrun.rsi.json
.venv/bin/freqtrade trade -c config/config.dryrun.ema.json
.venv/bin/freqtrade trade -c config/config.dryrun.freqai.json
.venv/bin/python scripts/dryrun_report.py
```

كل أمر `trade` في شاشة لوحده، ومن فولدر المشروع.
